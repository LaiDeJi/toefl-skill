| **SpeechAce** | 免费试用 | 发音评分 API |
| 本系统 `speaking_coach.py` | 免费 | 生成题目 + AI 评估 |
| 手机录音 App | 免费 | 录音后自己回听或传给 AI |

### 口语练习法
1. **Shadowing（跟读）：** 听 TED-Ed → 暂停 → 立即复述 → 对比
2. **即兴回答：** 用 speaking_coach.py 生成题目 → 计时 45 秒 → 录音
3. **回听分析：** 听自己的录音，检查停顿、文法、时间控制
4. **AI 评估：** 把文字版回答贴给 AI，依 rubric 评分

## 8. 开源工具链（本系统使用）

| 工具 | 用途 | 安装指令 |
|------|------|----------|
| `edge-tts` | 免费 TTS（Microsoft Edge 语音） | `pip install edge-tts` |
| `genanki` | Python Anki deck 生成器 | `pip install genanki` |
| `Kokoro TTS` | 离线高品质 TTS（82M 参数） | `pip install kokoro` |
| `Piper TTS` | 超轻量离线 TTS（可跑在 RPi） | 见 GitHub |

### edge-tts 推荐语音
| 语音 | 代码 | 用途 |
|------|------|------|
| Aria (女) | `en-US-AriaNeural` | 旁白、一般素材 |
| Guy (男) | `en-US-GuyNeural` | 教授、学术演讲 |
| Jenny (女) | `en-US-JennyNeural` | 女学生角色 |
| Andrew (男) | `en-US-AndrewNeural` | 男学生角色 |
| Michelle (女) | `en-US-MichelleNeural` | 学术顾问、正式通知 |
| Sonia (女) | `en-GB-SoniaNeural` | 英式口音练习 |

> 注：Microsoft 会不定期停用语音 ID，停用后 edge-tts 会丢出
> `NoAudioReceived`。合成失败时，先用上方指令确认语音是否仍存在
> （上表以 edge-tts 7.3.1 于 2026 年 10 月验证）。

```bash
# 列出所有可用语音
edge-tts --list-voices | grep en-

# 生成音频
edge-tts --voice en-US-AriaNeural --text "Hello world" --write-media hello.mp3

# 调整语速（模拟不同难度）
edge-tts --rate=-20% --voice en-US-GuyNeural --text "..." --write-media slow.mp3   # 慢速 Lv1-2
edge-tts --rate=+0%  --voice en-US-GuyNeural --text "..." --write-media normal.mp3 # 正常 Lv3
edge-tts --rate=+15% --voice en-US-GuyNeural --text "..." --write-media fast.mp3   # 快速 Lv4-5
```

## 11. 每周素材排程建议

自适应引擎（adaptive.py）会根据分数调整，但以下是基础排程：

### 基础期（Week 1-4）
| 日 | 听力素材 | 阅读素材 | 口语 | 写作 |
|----|----------|----------|------|------|
| 1 | VOA 1篇 | Wikipedia Simple 1篇 | — | — |
| 2 | BBC 6min 1集 | — | 跟读 TED-Ed 1支 | — |
| 3 | — | Nat Geo 1篇 | — | Build a Sentence 10题 |
| 4 | TED-Ed 1支 | — | Interview 2题 | Email 1篇 |
| 5 | BBC 1集 | The Conversation 1篇 | — | — |
| 6 | — | — | 跟读 15min | Discussion 1篇 |

### 强化期（Week 5-8）
- 听力升级：NPR Short Wave → 60-Second Science
- 阅读升级：Scientific American 短文
- 口语：每天 shadowing 15 分钟
- 写作：每两天一篇，AI 批改

### 冲刺期（Week 9-12）
- 听力：模拟考音频，只听一次
- 阅读：限时练习
- 口语：完整模拟（7 repeat + 4 interview）
- 写作：计时完成全部三种题型

## ⚠️ 避免使用的资源

| 类型 | 原因 |
|------|------|
| 2025 年或更早的 TOEFL 练习书 | 题型完全不同（没有 Listen & Repeat、Email 等） |
| 未标明「2026 format」的线上练习 | 可能是旧制题目 |
| 非授权的 TPO 外流版本 | 品质不稳定，可能有错误 |
| 纯机器翻译的素材 | 文法和用词可能不自然 |
| 只练模板的备考书 | 2026 AI 评分会检测模板并扣分 |
